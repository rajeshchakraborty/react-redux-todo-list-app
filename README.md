# React Redux Todo List App

This is a simple Todo List application built using React and Redux. The project demonstrates how to manage global state using Redux while building a practical and interactive web application.

It is a beginner-friendly project that helps in understanding how React components and Redux store work together.

## Project Overview

- The React Redux Todo List App allows users to:
- Add new tasks
- View all tasks
- Delete tasks

## Manage application state using Redux

The main goal of this project is to practice state management and understand how Redux handles data flow in a React application.

## Features

- Add a new todo item
- Display list of todos
- Delete a todo item
- Centralized state management using Redux
- Clean and simple user interface

## Installation and Setup

Follow these steps to run the project locally.

1. Clone the Repository
```
git clone https://github.com/rajeshchakraborty/react-redux-todo-list-app.git
```

3. Navigate to Project Folder
```
cd react-redux-todo-list-app
```

4. Install Dependencies
```
npm install
```

4. Start the Application
```
npm start
```


## After running the command, open your browser and go to:

http://localhost:3000

## How Redux Works in This Project

- The application uses a Redux store to manage the todo list.
- Actions are dispatched when a user adds or deletes a task.
- Reducers update the state based on the action type.
- React components automatically re-render when the state changes.
- This structure keeps the application organized and scalable.
